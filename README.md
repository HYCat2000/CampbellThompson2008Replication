# Campbell and Thompson (2008) Replication

Replication of:

Campbell, J. Y., & Thompson, S. B. (2008).
"Predicting Excess Stock Returns Out of Sample:
Can Anything Beat the Historical Average?"
Review of Financial Studies, 21(4), 1509–1531.

## Objective

Replicate the main out-of-sample stock return forecasting
results of Campbell and Thompson (2008) using Python.

Status: Work in progress
Current progress: data loaded and initial predictors constructed
